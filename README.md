# ValoDashboard V26 - Elite Tactical Intelligence

A professional-grade Valorant player dashboard built for speed, precision, and immersive tactical storytelling. This dashboard leverages Next.js 15, Tailwind CSS, and Framer Motion to deliver a "game-terminal" experience for checking player performance.

## 🚀 Deployment Ready

This project has been fully audited for production stability and performance.

### Setup Instructions
1.  **Clone & Install:** `npm install`
2.  **Dev Mode:** `npm run dev`
3.  **Production Build:** `npm run build && npm start`

## ✨ V26 Tactical Features

*   **V26 Tactical Aesthetic:** A custom-engineered design system featuring sharp "military-grade" cutouts, neon accents (Chaos Red, Neon Green), and glassmorphism.
*   **Protocol-Z Header:** Stable, high-precision navigation and theme toggle (Light/Dark) using `next-themes` and `framer-motion`.
*   **Battle History Protocol:** 
    *   Lightning-fast match list filtering by result and search by Agent/Map.
    *   **Instant Data Dossier:** Zero-delay match details retrieval.
    *   **Body Hit Intelligence:** Advanced SVG-based visualization of hit bone metrics (Head/Body/Legs).

*   **Elite Profile Sync:** Dynamic rank tracking with custom high-resolution **Immortal/Radiant** assets integrated directly into the UI.
*   **Immersive Map Sync:** Real-time map background rendering using official Valorant API assets for the exact match context.

## 🛠 Engineering & Optimization

1.  **Zero-Lag Interaction:** GPU-accelerated animations using `will-change` and optimized Framer Motion physics. Removed heavy CSS filters for better mobile performance.
2.  **Theme Stability:** Hardened `ThemeToggle` component with hydration-safe context management.
3.  **Responsive WebView**: Mobile-first architecture ensures the "Tactical Terminal" feel persists on tablets and phones.
4.  **Production Hardened**: Build checks pass successfully with optimized image handling via `next/image`.
